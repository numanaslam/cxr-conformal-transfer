# From-scratch run of 2026-10-02

Output of `python scripts\run_all.py` on a clean machine (RTX 5070), starting from the public
downloads. `results/` holds the result JSON of every stage and `logs/` the console output of
each stage in run order. Every number in the article comes from these files.

`s08_selective.json` (1 MB, the zero-shot risk-coverage curve, not used in the paper) is left
out. Stage `s23` writes no result file; its numbers are in `logs/27_s23.log`.

NIH split of this run (seed 42): train 78,607 / calib 10,711 / val 10,939 / test 11,863 images.

Added 2026-10-03 from the same machine and caches:
- `results/s33_seed42.json`: the re-split script run on the primary split (`--seeds 42`). It
  reproduces all four G1 rates and both NIH-calibrated G2 rules of the `clean` block of
  `s31_clean_protocol.json` exactly, so the gap between seed 42 and seeds 0 to 4 is the draw,
  not the code. The VinDr-calibrated G2 rows differ slightly because the two scripts halve the
  VinDr calibration set with different hash salts.
- The figure PNGs, regenerated by `s13_figures.py` with neutral labels (transferred / local,
  no "> target" annotation). `fig2_coverage.png` and `fig_score_shift.png` are the two
  appendix figures of the article.

The public archive omits `results/fig3_interpretability.png` and
`results/fig3b_concept_saliency.png`, because they reproduce radiographs from VinDr-CXR. Stages
`s13` and `s14` regenerate them from the downloaded images.
